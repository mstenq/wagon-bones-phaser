# Trail Tag Icon Image Prompt

Create a cohesive grid of small square game icons for a Western/Oregon Trail roguelike. Each icon should be readable at 32px or smaller: simple centered silhouette, one primary object, thick clean outline, limited detail, no text, no numbers, no UI frames unless specified. Use a consistent frontier-fantasy style across the whole sheet: weathered parchment background, dark brown ink outlines, muted gold highlights, dusty red accents, and subtle occult/holy glow only where noted. Keep all icons the same size, same camera angle, same lighting, and evenly spaced in a grid.
