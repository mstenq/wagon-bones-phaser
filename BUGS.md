### Oracle Deck - $8 - Uncommon
Before each trail event, draw 3 random tarot cards, if you predict the future correctly gain +8 mult.

Notes: Each category cooresponds to a tarot card. They'll only see the tarot card name, not what category it represents.

| Category     | Tarot Card           | Why it Fits                        |
| ------------ | -------------------- | ---------------------------------- |
| positive     | **The Sun**          | success, joy, fortune              |
| animal       | **Strength**         | lion imagery, beasts, instinct     |
| bandits      | **Seven of Swords**  | theft, deception, robbery          |
| demon_hunter | **Judgement**        | holy reckoning, purification       |
| navigation   | **The Chariot**      | travel, direction, movement        |
| stranger     | **The Fool**         | wandering traveler, unknown figure |
| uneventful   | **Four of Swords**   | rest, stillness, quiet             |
| wagon_damage | **The Tower**        | disaster, collapse                 |
| water        | **The Moon**         | tides, uncertainty, water imagery  |
| weather      | **Wheel of Fortune** | changing conditions, fate          |
