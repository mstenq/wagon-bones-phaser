# Trail Event Image Descriptions

AI image prompts for trail event scene art. One entry per event id in `src/data/trail_events.ts`.

Each entry has two prompts:

- **Primary** — full scene art (characters, animals, wagons, etc. as needed).
- **Secondary (spyglass preview)** — scenery only for Scout's Spyglass distant previews. No people, animals, wagons, demons, or other characters. Hint at what lies ahead through landscape, weather, and environmental details only.

Every prompt ends with **32-bit pixel art style** and **nostalgic retro game aesthetic**.
